# RPM

<Color id="nord_accent">Revolutions per minute (RPM)</Color> is proportional to a machine's throughput: **Throughput ∝ RPM**.

# SU

<Color id="nord_accent">Stress units (SU)</Color> defines how much stress you have produced/consumed: **SU = Base Value × RPM**.
